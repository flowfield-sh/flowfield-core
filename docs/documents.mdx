---
title: Workspace documents
description: Maintain shared guidance and select the revisions workers need.
---

**Documents** holds versioned Markdown for purpose, conventions, architecture and specifications. **Workspace guidance** is always included in newly prepared tasks. Ask the Coordinator to create custom documents; you can edit them directly. Keep current work status in tasks and repository conventions in their authoritative files.

## Write and review

Choose **Edit**, write Markdown, use **Preview**, then save. Each changed save records a revision, author and time. **View document** returns to saved content while retaining your draft. If another edit arrives, preserve your changes, choose **Load latest** and reconcile them; stale saves cannot overwrite newer content.

![A workspace document and its revision history beside the Coordinator](/images/documents.png)

Choose a **Revisions** entry to read earlier content. **Restore** copies it into a new revision, preserving intervening history. Document links survive renames; revision links open exact saved content.

Ask the Coordinator to delete a custom document after removing it from defaults and unfinished task selections. Existing evidence links retain its history; restoring a revision returns it to the list. Workspace guidance can be cleared but not deleted.

## Supply worker context

**Saving a custom document does not select it for workers.** Choose **Edit → Use this document** to set its future audience:

| Selection | Applies to |
| --- | --- |
| Projects | New preparations for the selected projects; also editable in **Project settings → Worker documents**. |
| Include for tasks without a project | New preparations for workspace-only work such as research, screenshots or PDFs. Off by default. |
| Task-specific selection | One outcome; ask the Coordinator to select the document or pin an exact revision. |

Choose **Required source** for rules the worker must read fully, or **Reference material** for optional supporting context. The same document can have different purposes in different projects/tasks. Main workspace guidance is always required.

Keep defaults focused on obligations shared by future tasks. Task selections override an inherited purpose/revision; omitting a default does not exclude it. For long mixed documents, ask the Coordinator to capture applicable rules and exceptions in the task agreement or a focused required source, citing the original revision. Keep the original required if necessary details remain only there.

Preparation freezes the combined selection: workspace guidance plus at most 20 custom documents and 1 MB of text. Workers receive a bounded brief and access to exact saved content. Prose links do not copy their targets. Expand **Worker documents** in attempt evidence to inspect the frozen revisions; source size and token usage do not prove reading or understanding.

## Adopt changes deliberately

Document/default edits preserve prepared assignments and running attempts. **Newer source revision available** on an unfinished task is informational; it does not block work or invalidate results automatically.

Ask the Coordinator to assess affected tasks, prepare upcoming work again when it should adopt changes, and reconcile work already started. Answer continuations retain their original sources. Completed tasks keep their delivered snapshots.

## Work with the Coordinator

Each message captures the main guidance revision and any saved document open beside the conversation. The Coordinator can read and maintain these documents through the same revision checks.

During project adoption, agree which repository instructions to reference or incorporate. Flowfield preserves existing files and does not import them automatically; native harnesses may still load their own instructions. Document prose does not change queue, model, permission or code-approval settings.
