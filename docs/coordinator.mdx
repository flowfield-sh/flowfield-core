title: Coordinator
description: Plan work and capture tasks beside the board.
---

The Coordinator stays beside your board and task feeds. Explore an idea, shape it into
tasks, and refine the plan as implementation reveals new requirements or design questions.
Open a card to discuss that task without losing the conversation.

## Start planning

Set up a supported [agent](/agents/overview),
then check detected paths in **Settings → Harnesses** if needed.
Add an existing project using **Add project → Choose directory** or `flowfield project init`.
Choose the Coordinator's harness, model and access controls beside the input. Models load
automatically; save your choice to start. Worker settings are independent. The Coordinator
uses the service host's tools and credentials and receives Flowfield tools automatically.

Write your message and select **Send** (or press Enter). Use Command/Ctrl+Enter or
Shift+Enter for a new line. Send is available once you have saved your model settings.
The coordinator manages work through project-scoped Flowfield tools, including destination,
setup/check commands, result-preview settings and setup validation. Validation runs in a
separate checkout without starting a model or enabling the worker queue. You can also ask it
to configure the project or local environment directly, within its selected access mode.
These setup changes affect the project directory immediately; they do not produce a task
result for approval. Agreed implementation work belongs to task workers.

Ask the Coordinator to configure workers, run or pause the queue, answer worker questions,
request changes, try results or recover blocked work. You can explicitly approve a specific
code result in chat; the Coordinator records that exact approval and Flowfield delivers it
without a second confirmation. These actions are also available in task feeds.

Use the model button to change harness, model, effort or access for the next message.
Switch harnesses when idle or after confirmed Stop. A switch starts a fresh native session
with saved Flowfield context. See each [agent's page](/agents/overview) for continuation and
access modes. Save applies your choices; Cancel or closing the popup discards edits.

Permission requests appear in the chat and **Inbox**. Answer while the turn is waiting;
Stop closes its requests. Tool permission is separate from approval to deliver worker code.

## Composer controls

The input grows as you write. Use the paperclip, drop files onto the input, or paste an image
to attach it. Remove an attachment with its × button before sending. Sent files are saved
with the conversation and can be downloaded from their message links.

You can attach up to four files: UTF-8 text/code up to 64 KiB each, or PNG, JPEG and WebP
images up to 2 MiB each. Their contents accompany the message sent to the agent; images
require image support from the connected harness. Coordinator attachments remain part of
its native session history, subject to the harness's context management. Reattach a file if you
start a new session or need details that compaction has omitted. Previously sent files
remain available to download. Task-feed answers and feedback accompany separate worker
attempts; attach files again when later input needs their contents.
Each project has 128 MiB of attachment storage. Unsent uploads expire after 24 hours.

Type `/` and select **Load commands** to see the Coordinator commands. Use arrow keys
and Enter to select, then send. Escape returns to ordinary writing.

| Command | Effect |
| --- | --- |
| `/status` | Show native model/settings or context status. |
| `/compact` | Compact the existing native conversation. |
| `/mcp` | Show native MCP connections. |
| `/skills` | List available skills. |

These four commands map to each harness's native controls. Discovery and inventory commands
send no model prompt; compaction may use the model. Commands take no arguments or attachments.

**Fast mode** appears as a lightning button beside model settings when the selected model
supports it. Select it to save Fast on or off for subsequent messages. It provides faster
responses with increased usage; hover or focus the button for its description and current state.
Changing models starts at normal speed. Running turns keep their captured settings.
Saved choices are checked in the background when the project opens or the browser reconnects.
Task workers have the same lightning control for subsequent attempts. Fast defaults to off
for each task, with no project-wide speed setting.

Hover or focus the context ring for the agent's reported context usage. During a turn it
shows that turn's latest report when available; otherwise it shows **Last reported** usage.
This saved report survives reloads and restarts, even if later commands do not report usage.
Starting a replacement session clears the previous session's report. The ring stays empty
until the agent reports usage. Context occupancy is separate from billable token usage.

## Focus on a task

Open a board card to show its definition and feed beside the same coordinator conversation.
Project tabs stay available: **Board** closes the task, while the back arrow before its
title returns to the previous view. On narrow screens, switch between
**Work** and **Coordinator**.

The task reference above the composer shows what your next message refers to. Remove it
to discuss the project without a selected task. Sending records that task and its revision;
changing cards later does not change earlier messages or start a new chat. A result permalink
also attaches that exact result. The coordinator reads current task state before making changes.
Session commands still operate on the coordinator conversation as a whole.

Discuss planning, card changes and result questions here. Task feeds retain worker activity,
questions, answers, feedback and exact-result approval with optional testing notes. Their text inputs are for those specific
interactions. Selecting a task never launches a worker.

## Follow and stop

Replies and tool activity stream in order. Tool activity appears in grey, and each reply
shows its current status. One coordinator turn can run per project, independently of worker
slots. You can write your next draft while it runs, then send when it finishes.

**Stop** ends the selected coordinator turn. Saved task changes remain, and task workers
continue independently. If a connection fails, the retained turn explains whether it stopped
or needs recovery. Flowfield never replays an interrupted prompt. If native cleanup could not
be confirmed, stop the remaining coordinator process on the host before choosing
**Confirm coordinator stopped**.

## Continue later

Each project has one ongoing coordinator conversation. Messages, public output and turn settings
are saved by the service. Older messages load on demand and stay visible as new replies arrive.
Use **Read full reply** for shortened previews and **Retained output** for tool details.
**Working…** appears during an active turn; **Waiting for permission** indicates that your
input is needed.

With compatible unchanged settings, messages resume the same native session, including
its tool history and native context management, across turns and service restarts. Each turn gets a fresh scoped
Flowfield connection. Stopping a turn ends its processes without deleting the saved session.

If the harness cannot resume, check it on the service host and retry, or choose
**Start new session**. Your saved Flowfield conversation remains available. Fresh sessions
receive recent exchanges that fit the reported context headroom and can retrieve older
messages through history tools. Native tool history stays with the original session;
reattach earlier files when their contents matter. Interrupted prompts are never replayed
automatically.

If cleanup remains uncertain, inspect and stop the remaining native work before confirming
that the exact turn has stopped. Record ongoing work in tasks and durable decisions in
your repository.

Resize the chat and work panes on a wide screen. On narrow screens, switch between
**Coordinator** and **Work**; switching preserves the current draft.
