title: Installation
description: Install Flowfield with uv or pip and manage its local service.
---

## Recommended: uv

With [uv](https://docs.astral.sh/uv/getting-started/installation/) installed:

```sh
uv tool install flowfield-core
```

Requires Python 3.12+, macOS 13+ on Apple Silicon or glibc 2.28+ Linux on arm64/x64. If `flowfield` is missing from PATH, run `uv tool update-shell` and open a new terminal.

## Alternative: pip

Use Python 3.12 or newer in a dedicated virtual environment:

```sh
python3 -m venv ~/.local/share/flowfield-venv
~/.local/share/flowfield-venv/bin/python -m pip install flowfield-core
```

Activate that environment to use the shorter command:

```sh
. ~/.local/share/flowfield-venv/bin/activate
```

## Set up your harnesses

Install and sign in to [Codex](/agents/codex), [Claude Code](/agents/claude-code) or [Pi](/agents/pi) on the same machine. Flowfield includes the integrations; code tasks also need Git.

Choose **Verify installation** in **Settings → Harnesses**. See [agent setup](/agents/overview#setup) if detection, sign-in or model access fails.

## Start and stop

```sh
flowfield serve
```

The service opens [localhost:8765](http://127.0.0.1:8765). Use `--no-open` to keep the browser closed; Ctrl-C stops it. For another port, use `flowfield serve --port 8770` and connect clients with `flowfield --port 8770 …`.

Continue with [Getting started](/getting-started#create-a-workspace).

## Update

**Settings → Updates** shows available releases and update commands. Flowfield checks automatically while running; choose **Check for updates** for a manual check.

Disable automatic checks in **Settings → Updates** or with `FLOWFIELD_UPDATE_CHECKS=0`.

Stop the service before upgrading:

```sh
uv tool upgrade flowfield-core
flowfield serve
```

For the pip environment:

```sh
~/.local/share/flowfield-venv/bin/python -m pip install --upgrade flowfield-core
~/.local/share/flowfield-venv/bin/flowfield serve
```

Your workspaces and settings are preserved. See the [release notes](https://github.com/flowfield-sh/flowfield-core/releases) for changes.

To review work before the queue starts again, turn off **Auto-start worker queue** in workspace Workers settings before stopping the service.
