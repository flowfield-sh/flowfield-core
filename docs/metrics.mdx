Open **Metrics** in the sidebar to compare activity across tasks, agent types, harnesses or models. Metrics supports Codex, Claude Code and Pi.

![Workspace Metrics with shared filters and totals](/images/metrics.png)

## Explore workspace activity

Choose a **Period**, or enter **From** and **To** in your local time and select **Apply**. Use **Activity** to select all work, the Coordinator or a task, and **Group by** to compare agent types, harnesses or models.

The charts and task table share these filters. Click a day or hour to narrow the range; use arrow keys and Enter when navigating by keyboard. Sort the Tasks table by Tokens, Cost or Duration, then open a task for its details. Bookmarks retain your selection.

Tokens and Cost use stacked bars. Duration uses separate lines because parallel work overlaps and should not be added together.

![Token and cost bars for the selected period](/images/metrics-cost.png)

## Inspect a task

Tasks show lifetime **Tokens**, **Cost**, **Duration** and **Corrections**. Hover, focus or tap a callout for details and the Worker/Reviewer breakdown. On narrow screens, scroll the row to see all four.

![Task metrics and recorded work](/images/task-metrics.png)

Corrections counts work started to address feedback, excluding retries and answer continuations.

## Understand the numbers

- **Tokens** are reported by the harness, including cached input without double-counting.
- **Cost** estimates what the reported token usage would cost at USD API rates, calculated separately for each model using its input, output and cache pricing. This includes helper models. Tooltips show the pricing date; earlier costs keep their original rates. Values below one cent show `<$0.01`.
- **Duration** counts overlapping running time once and excludes idle gaps.

Unavailable measurements show `-`, including historical usage without pricing data.
