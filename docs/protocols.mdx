Flowfield uses installed Codex and Pi processes directly, and the official Agent SDK with
installed Claude Code. Native adapters map models, settings, public activity, sessions and
Stop into shared application controls. See [Agents](/agents/overview) for setup and capabilities.

## MCP tools

[MCP](https://modelcontextprotocol.io/docs/getting-started/intro) connects agents to tools
and context. Flowfield's tools use the same revisions, saved answers and exact-result
approval rules as the GUI and CLI. Discovery supplies names, descriptions and schemas.

Built-in Coordinator and workers receive scoped connections automatically. Each connection
belongs to its project or task attempt. For external conversations, use the
[standalone connection steps](/agents/overview#standalone-conversations).

The Coordinator reads older saved exchanges with `get_coordinator_history` and full text
with `get_text`. Follow the returned cursors and text revisions. Native tool history and
private reasoning remain with the harness. Workers receive their task-bound context.

## Execution and recovery

Compatible Coordinator sessions resume native history. Fresh sessions use saved Flowfield
context. Stop interrupts active turns, stops supported native background work and closes
owned processes. Unconfirmed cleanup retains ownership until recovery. Arbitrary detached
services remain outside that guarantee.

A tool call or native permission decision never approves delivery of a worker's code.
