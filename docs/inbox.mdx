**Inbox** stays pinned beside the Coordinator. It brings together decisions that need you; Task Board tracks the execution plan.

![A question and a code result in Needs me, beside the Coordinator](/images/inbox.png)

## Needs me, Delivered and History

| Tab | Contents |
| --- | --- |
| Needs me | Unresolved questions, code approvals, tool permissions and recovery actions. The badge counts actionable requests. |
| Delivered | Completed task outcomes, ordered by delivery time. Open exact results to access code or retained files; opening does not remove them. |
| History | Resolved requests and earlier responses, including answers awaiting Coordinator follow-up. |

Open a row to read and respond. Inbox keeps your list selection and position.

| Item | Next action |
| --- | --- |
| Question | Choose a suggested answer or write your own, then send. Selecting a suggestion only fills the composer. |
| Result | Read the evidence, optionally try the code, then request changes or approve and integrate the exact result. |
| Intervention | Follow the displayed recovery action. Approved code blocked at delivery remains actionable here. |
| Tool permission | Allow or deny while the native session waits. This grants no code-delivery approval. |

Saved worker answers continue work when the queue permits. Planning answers need Coordinator follow-up. Answering or retrying leaves a paused queue paused.

## Open the exact request

The task badge opens its purpose and history; results have their own [review controls](/review).

Failed saves preserve your input. Drafts survive tab switching during the session; leaving or reloading warns before discarding them. If someone else resolves the request, discard your draft when ready.

## Notifications

Configure optional in-app and system alerts in **Global settings → Notifications**. System notifications require browser permission and an open Flowfield page. Alerts link to the relevant item.
