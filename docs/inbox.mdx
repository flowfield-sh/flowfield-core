**Inbox** stays pinned beside the Coordinator. It brings together decisions that need you; Tasks Board tracks the execution plan.

![A question and a code result in Needs me, beside the Coordinator](/images/inbox.png)

## Needs me, Delivered and History

| Tab | Contents |
| --- | --- |
| Needs me | Unresolved questions, code approvals, tool permissions and recovery actions. The badge counts actionable requests. |
| Delivered | Completed task outcomes, ordered by delivery time. Open exact results to access code or retained files; opening does not remove them. |
| History | Earlier responses, including answers awaiting Coordinator follow-up and retained drafts on resolved requests. |

Each request names its source and offers response controls. Expand evidence or follow the task link for context.

| Item | Next action |
| --- | --- |
| Question | Choose a suggested answer or write your own, then send. Selecting a suggestion only fills the composer. |
| Result | Read the evidence, optionally try the code, then request changes or approve and integrate the exact result. |
| Intervention | Follow the displayed recovery action. Approved code blocked at delivery remains actionable here. |
| Tool permission | Allow or deny while the native session waits. This grants no code-delivery approval. |

Saved worker answers continue managed work when queue, dependencies and capacity permit; no separate apply step is needed. Planning answers require the Coordinator to resume and reconcile them. Answering or retrying never enables a paused queue. Once an answer is assigned to a continuation, correct it as new input rather than replacing consumed history.

## Open the exact request

Use **Open in work tab** to read a request beside the Coordinator while Inbox keeps its view. The task badge opens its purpose and history; results have their own [review controls](/review).

Responses remain bound to the original request or result. Newer records cannot silently replace the one you are answering. Failed saves preserve input; drafts survive switching or closing tabs in the current session. If another session resolves the request, discard your retained draft when ready. Reloading or leaving warns about unsaved input.

## Notifications

Configure optional in-app and system alerts in **Global settings → Notifications**. System notifications require browser permission and an open Flowfield page. Alerts link to the relevant item; dismissing one answers nothing and approves no result.
