---
title: CLI
description: Run the service, connect external agents and diagnose the local installation.
---

Use the CLI to run Flowfield and connect agents in your terminal or editor. Manage work and settings in the browser or through [MCP](/mcp-integration). `--help` lists the options at each command level; `--json` produces structured data, with errors on stderr and a nonzero exit status.

## Service and storage

```sh
flowfield serve
flowfield --version
flowfield version --json
flowfield update status
flowfield update check
flowfield storage status
```

`serve` opens the browser in an interactive terminal. Use `serve --no-open` to print the URL without opening it, and Ctrl-C to stop the service. Global `--port` or `FLOWFIELD_PORT` selects the service; `--data-dir` or `FLOWFIELD_DATA_DIR` selects its data directory.

Update commands report availability; they do not install releases. Storage inspection works offline. See [installation](/installation#update) and [storage](/storage#inspect-storage).

## External agents

```sh
flowfield integration connect codex
flowfield integration status codex
flowfield integration disconnect codex
```

Use `codex`, `claude-code` or `pi`. [Connect an external agent](/mcp-integration) explains connection scope, disconnection and optional project guidance.

For guidance in an adopted repository, use `integration guidance preview`, `install`, `show` or `remove`. Outside the repository, pass `--project ID`. `export --part coordinator` prints the packaged skill without changing files.

## Host diagnostics and recovery

```sh
flowfield harness status codex
flowfield harness settings codex
```

`status` inspects detected native paths offline without launching an agent. `settings` reads readiness and discovery ownership from the running service. Change paths in **Settings → Harnesses**, or ask a connected agent to configure them through MCP.

If discovery is held after an interruption, inspect and stop the remaining native processes on the service host, then confirm the exact discovery ID:

```sh
flowfield --port 8770 harness confirm-stopped codex --discovery DISCOVERY_ID
```

Use the same port as the service being recovered. See [agent recovery](/agents/overview#recover-setup-and-discovery).
