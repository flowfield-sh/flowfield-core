## Setup

Install [Claude Code](https://code.claude.com/docs/en/setup) and sign in on the machine running Flowfield. Flowfield uses the official Agent SDK with your installed CLI. The SDK helper ships with Flowfield; no additional Node runtime is required.

In **Settings → Harnesses**, keep detected paths or override the executable and configuration directory. Accounts stay in Claude Code. See [shared setup](/agents/overview).

If a turn fails because Claude cannot authenticate, sign in through Claude Code on the machine running Flowfield. Use the executable and configuration directory shown in **Settings → Harnesses**, choose **Verify installation**, then resend your message. A terminal using a different configuration directory can be signed in while Flowfield's Claude session is signed out.

Keep the configuration override blank when using Claude's default setup. For an explicit `CLAUDE_CONFIG_DIR`, use the same path spelling as your terminal; on macOS it can affect which Keychain credentials Claude uses.

## Models and access

Models and effort levels come from Claude, with resolved model versions shown in the picker. Access modes are **Default**, **Accept edits**, **Auto (review actions)** when supported, and **Bypass permissions**. Claude organization policy still applies. Plan and Fast are not exposed.

Choose the Coordinator, Workers and Reviewer independently. Task **Settings → Worker** and **Reviewer** can override the defaults for subsequent attempts. See [worker setup](/worker-setup).

The Coordinator supplies workspace member repositories as additional directories to Claude Code.
The selected native permission mode still applies. Workers continue in their isolated task checkouts.

## Commands

The Coordinator supports `/compact`, `/status`, `/mcp` and `/skills`. Compaction uses Claude’s native `/compact`. Status reports model/context usage, MCP lists native connection status, and skills lists the SDK’s available skills.

## Sessions and Stop

Unchanged settings resume the native Coordinator session. Changing model, effort or access mode starts a fresh session. Stop interrupts the turn and stops observed native tasks; unsupported goal, Monitor or workflow activity can require recovery.

See [Coordinator recovery](/coordinator#stop-and-continue-later) for saved history, fresh sessions and uncertain cleanup.

## Native customization

Claude loads native user/project settings, instructions and skills. Managed sessions use Flowfield’s scoped MCP configuration. Native question and Plan tools are replaced by Flowfield’s task conversation workflow.

## Standalone conversation

Use the [shared connection steps](/agents/overview#standalone-conversations) with `claude-code`:

```sh
flowfield integration connect claude-code
```
