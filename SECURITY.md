# Security reporting

Report potential vulnerabilities through [GitHub private vulnerability reporting](https://github.com/flowfield-sh/flowfield-core/security/advisories/new). Keep vulnerability details out of public issues and pull requests.

Include the affected Flowfield version, operating system, reproduction steps, and potential impact. Use a minimal example without credentials or private project content. When possible, confirm whether the latest published release is affected.

Maintainers will assess the report and coordinate a fix and disclosure with you. Security fixes target the latest published release.
